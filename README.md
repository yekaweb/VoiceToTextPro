**VoiceToText Pro** (Phoenix Voice Studio) is a professional, offline-first speech processing suite for Windows. It provides offline Speech-to-Text, multi-speaker Text-to-Speech (Piper ONNX & Microsoft Neural Voices), Voice Conversion, Subtitle Studio, and Social Media Media Downloader.

---

## ✨ Features

- 🎯 **Offline Speech-to-Text**: High accuracy offline transcription powered by Whisper & Vosk.
- 🗣️ **Neural Text-to-Speech (TTS)**: Piper ONNX offline engine + Microsoft Edge Neural Voices (`Dilara`, `Farid`).
- 🎭 **Voice-to-Voice (V2V)**: Voice conversion & speaker cloning pipeline.
- 🎬 **Subtitle Studio**: Professional SRT subtitle editor with auto-sync and AI corrections.
- 📥 **Media Downloader**: Integrated YouTube, Instagram, and web video/audio downloader.
- 🎨 **macOS Sonoma Dark Glass UI**: High density, zero-scroll proportional grid interface.
